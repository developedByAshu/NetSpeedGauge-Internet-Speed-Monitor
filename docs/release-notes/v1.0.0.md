First release.

- Live upload and download speed on the Windows taskbar
- Data usage by day, week, month and year, kept for up to 2 years
- Mbps or MBps, colours, arrows, font, light and dark
- Never connects to the internet

Take `NetSpeedGauge-x64.exe`, or `NetSpeedGauge-arm64.exe` on a Windows on ARM PC. Tested on Windows 11. Windows 10 and ARM should work but are untested, so open an issue if something breaks.

Windows may show a SmartScreen warning because the program is not code signed yet. Choose **More info**, then **Run anyway**.
